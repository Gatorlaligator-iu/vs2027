# Veille stages

Toutes les heures, GitHub Actions lit les pages carrières listées dans `sources.yaml`,
garde les stages / graduate programmes dans tes villes cibles, et ouvre une **issue**
pour chaque nouvelle offre. GitHub t'envoie un email (et une notif sur l'app mobile GitHub).

- Lancer à la main : onglet **Actions** → *Veille stages* → **Run workflow**
- Voir l'état des sources : le résumé de chaque exécution dans l'onglet Actions
- Ajouter un cabinet : copier un bloc dans `sources.yaml`
- Le premier passage ouvre une seule issue « Tracker initialisé » avec les offres déjà en ligne.
